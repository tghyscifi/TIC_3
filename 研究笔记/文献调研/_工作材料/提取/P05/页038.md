目前，类脑计算芯片大多采用的是分布式众核架构[133]，在核粒度层面上采用
存算一体的架构。单芯片内部的物理 核布局结构差异大 ，部分采用树状或层状如
Briansales，Neurogrid 等；部分芯片诸如 Loihi，TrueNorth，Tianjic 等采用 2D Mesh
的多核拓扑结构。与集中式众核的映射所采取的基于时间粒度的映射方案不同，器
件粒度存算一体的神经形态芯片 大多采取基于空间粒度映射方案。 由于采用分布
式存储，每个 Fcore 内部的存算资源有限，映射过程的先决条件是神经网络的参数
容量的分配，即保证芯片可以容纳被执行任务的空间参数。 其次，基于多模态的功
能核，根据计算的指令任务，对指令任务按资源进行展开映射。 最后是芯片的映射
物理部署，根据数据传输关系和传输的数据量进行物理部署，保证在物理路由没有
死锁的情况下尽可能的降低路由延迟和路由功耗。 
TrueNorth 全数字脉冲神经网络芯片，单个芯片内部 Fcore 采用 2D mesh 结构。
与天机的第二代芯片一样每个 Fcore 只执行单一的指令任务。TrueNorth 芯片拥有
自己一套的映射工具 VLSI。资源调度映射采用力引导算法，和基于 core 的功能对
任务进行全展开映射。物理映射采用启发式算法来解决 NP 问题，减少片间通信，
优化节点与节点之间的曼哈顿距离，最大化输入和输出的吞吐率，因此降低路由传
输功耗。并且优化总的脉冲传输距离进而优化吞吐率实现高帧率[109][110]

Loihi 基于 Python API 开发脉冲神经网络的编译器和运行库[113]通过封装，用
户可在不访问硬件的情况利用 Python 包研究脉冲神经网络的资源调度映射。首先
以最小化输入映射总数，对资源进行分配。 对于物理映射Loihi 芯片采用贪心算法，
优化芯片产生的路由功耗，进而求出近似最优解[113]。该文并未提供贪心算法与其
他算法的数据对比。
