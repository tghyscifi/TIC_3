映射原本是一个函数集合中的概念，X 到 Y 之间建立的对应关系被称为映射。
对于芯片领域尤其是分布式众核架构芯片，映射是指将神经网络部署到众核架构
芯片上。按照马尔科夫性质和马氏过程定义，本文将映射过程分解为三个阶段。对
多层神经网络按层进行分组阶段作为第一个阶段。 针对拆分后的每一组，对其分配
调度 core 簇作为第二阶段。将分配分配调度 core 簇部署到真实的实际芯片物理位
置上作为第三阶段。第一阶段为计算任务自身的时空资源调整阶段， 旨在降低不同
组之间的存算负荷的不平衡性。 第二阶段： 针对已完成时空资源调整的单一固定的
计算任务，结合此计算任务的神经网络特征对其内部维度进行拆分，即分配部署的
core 簇阵列(资源调度)。第三阶段：针对每个计算任务已经分配的 core，将其部署
到物理芯片上(物理映射)。将此三个阶段看作映射的 3 个子空间。如下图所示：
