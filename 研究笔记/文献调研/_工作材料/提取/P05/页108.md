静态时分多网络任务所面临的物理映射相对简单，尽管任务是可以不固定的，
一种物理映射的优化方法 若能对一个网络适用 ，则适用于多个不同的网络在时间
上分阶段处理。因此对于静态时分多网络任务仅需要研究静态单网络任务的物理
映射即可。 对于静态空间多网络任务，不仅研究静态单网络任务的物理映射而且需
要研究多个网络之间的布局，在碎片化(资源利用率)与吞吐率中寻找一个代价，进
而使众核架构芯片的空间利用率最高并且使物理延迟最小。 
静态单网络多 core 簇任务的物理映射主要面向流水 core 簇和单个 core 簇内部
数据传输优化。例如将一个 ResNet 50 分成 18 个 Block，每个 Block 分配一个 core
簇，每个 core 簇由多个核构成。其中，相邻 core 簇之间存在着数据传输，core 簇
内部的 core 与 core 之间也存在着数据的传输。本文第三章所研究的理论均是针对
单个计算网络任务的研究，将单一个网络分解为多个 core 簇计算等价于将单个计
算任务分解成多 core 簇任务。本章节通过对单一的一个 core 簇进行物理映射研究
，并研究其内部的交叠数据、 部分和数据、 维度调整数据的传输对路由延迟和功耗
的影响。 
神经形态芯片往往采用多个 core 簇流水的处理计算任务，每个 core 簇分配的
比较规整。采用随机网络任务分布下的物理映射并不实用，从计算机系到本课题组
在随机网络任务的分布下物理映射研究最终均未被用于天机系列芯片的映射中。
