2. 针对单一的流水 core 簇所分配的计算任务，本文提出了三种资源调度模型：
循环式资源调度，非循环式资源调度、混合型资源调度。对于资源调度中可能出现
的数据交叠问题、部分和问题、维度调整问题进行了详细地分析并引入单任务的时
空映射极限的概念。 并且证明循环式资源调度可以达到时空映射的极限。在实际应
用中，可以根据每种调度模型的特点， 结合不同硬件平台的资源约束， 适当的选取
不同的资源调度方法。例如循环式资源调度更加适用于矩阵计算，非循环型适用于
小参数量的神经网络，混合型适用于大参数量的卷积神经网络的计算。 
3. 针对三种不同资源调度方案，分别提出三种不同的物理映射 的优化策略。
针对非循环式资源调度，提出一种将 4D 的 core 簇形式映射到 2D 平面的快速分
层算法，以降低 NP 问题的搜索空间。该快速分层算法与模拟退火算法，遗传算法
进行对比，能显著地降低延迟。理论和实验证明， 快速分层算法得到的物理延迟可
以接近传输延迟极限。 针对循环式资源调度，提出了快速的汉密尔顿回路算法，理
论和实验证明，汉密尔顿回路算法得到的物理延迟可以逼近传输延迟极限。针对混
合型资源调度，构建欧拉回路算法与拆分维度的快速分层算法的混合策略。针对多
个 core 簇，构建了基于深度优先算法实现寻找多条长度不同的汉密尔顿回路。 
4. 针对芯片的计算效率提升，对于芯片算力单元的 MAC 阵列尺寸匹配效率、
原语利用效率，分布式众核的存算比例与映射效率关系分别进行分析，进而构建
MAC 结构、MAC 尺寸、存储容量与计算效率四者之间的理论模型。通过仿真证
明：在特定的数目 MAC 下，与 2D MAC 阵列相比高维 MAC 阵列与神经网络的
尺寸匹配效率高，原语利用效率略低。在特定的数目 MAC 下与 2D MAC 阵列相
比，高维 MAC 阵列尺寸匹配效率与原语利用的乘积高。通过仿真证明： 不同结构、
尺寸的 MAC 阵列应匹配合适的 MEM 存储容量，并不是 MEM 存储容量越大越
好。 
5. 基于四者之间的理论模型并结合循环式资源调度策略，本论文对芯片架构
进行了优化与改进。 设计的芯片架构采用 3D 结构 MAC 阵列。并基于 3D MAC 阵
列对智能信息的存储方式、 硬件地址系统、 流水系统等进行优化设计。本论文开发
了仿真系统， 利用该系统对神经网络的映射和性能进行了全面的分析和测试。 这一
系列工作不仅提升了芯片的计算效率和处理能力，也为未来芯片设计提供了新的
研究方向和实践经验。
