3.3 资源调度的数据分配算法 
3.3.1 图像数据拆分与数据分配 
经对神经网络分组完毕后得到完整的一组任务，其所分配的 core 簇可按四维
的结构模式(M，N，J，I)。其中 M、N、J、I 分别表示输入深度、 输出深度、 宽度、
高度上分配的数目。将一组计算任务分配到这一 core 簇上，需要众多 core 同时、
并行完成。在资源调度中 需要对数据进行拆分 ，对于图像的拆分记作三维的拆分
(M，J，I)，拆分完毕后需要将图像数据分配到每个 core 上。另一方面数据的存储
次序不同的硬件架构不同，导致拆分的数据在每个 core 中的顺序与原来未拆分的
存储顺序不同。 假定存储顺序是先深度方向、 后宽度方向、 最后高度方向，如图 3.7
所示：从图中可以看出计算任务数据按照一定规则和顺序存储。图中的 x,y,z 分别
表示宽、高、深。假定图像为拆分前的宽、高、深依次为 Fx、Fy、Fz。假定存储
特点按照 32B 的数据存储在一个单位地址中。为了简化表征关系，数据按向量进
行表征。
