一个神经网络可以被分解为多个不同层数的网络簇，每个网络簇被分成多个不
同的 core 进行流水计算。基于循环式资源调度的多个 core 簇其物理映射为多条汉
密尔顿回路。 由于汉密尔顿回路在2D 上进行拓扑具有很强的灵活性，除了规整的
方形还可以有很多不同类型的汉密尔顿回路。如下图 4.35 所示：(a)表示 L 型，(b)
表示凹型，(c)表示凸型，(d)表示不规则其他类型。 因此在一个2D 平面上，可以通
过算法，很快找到多个长度不同的汉密尔顿回路。在一个固定的 2D 平面上，寻找
多个长度不同的汉密尔顿回路，其算法思想如下： 
第一步： 构建不同长度回路的列表，并定义上下左右四个方向可以移动的点(0，
-1)，(0，1)，(1，0)，(-1，0)。 
第二步：采用深度优先搜索算法进行遍历， 如果某个回路的长度达到预设值，
则判断回路的最后一个点是否与起始点相邻。 如果相邻， 则从下一个未被遍历过的
点开始搜索下一个回路；如果不相邻，则回退至上一个点继续搜索。 
第三步：利用深度优先的方法尝试在四个方向扩展回路进行上一步的深度搜
索，直到搜索完毕。
