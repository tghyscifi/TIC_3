2.3.1 均衡时空密度数据共享映射方法 
深度神经网络的相邻计算任务或是相邻 Block，往往其时空密度不均衡。
例如在 ResNet 50 的 Block 15 的参数容量 5888 KB，计算量 592 MOPs，Block 
14 的参数容量，计算量为 438 MOPs。针对这一情况，提出采用分布式众核多
个 core 簇之间共享参数的方案。如下图 2.6 所示：第一层的计算任务的参数量
特别少，第二层任务的参数量相对大。 当用4 个 core 的时候，第一层计算任务
所分配的每个 core 内部存储空间还有很多剩余。第二层计算任务部署在 4 个
core 的时候，其每个 core 内部的存储空间表现不足。为了满足映射的先决条件
即存储容量，对第二层计算任务分配 8 个 core 则浪费计算资源。
