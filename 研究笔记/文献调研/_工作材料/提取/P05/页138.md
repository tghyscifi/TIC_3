4.6.2 大型矩阵的闭环回路映射 
对于大型矩阵的测试,实验中选取大小为 1024x1024 的矩阵，然后通过级联
相乘的方式进行计算。级联的数目依次设置为 2、4、10、50、100 个。然后分
别在 CPU 平台、GPU 平台、英伟达 TX2、标准 TPU 平台进行测试，并记录其
时间。天机 X 芯片采用的是众核架构，当矩阵级联相乘的数目不断增多时，可以
通过增加 core 的数量来满足需求。因此，我们将 core 的分配数目设定为 4、16、
64、128、128。由于天机 X 芯片内部没有矩阵乘原语指令，因此只能将矩阵乘
拆分成多条全连接原语进行实验。对于矩阵乘天机 X 芯片的调度方案采用 3.4.4
小节的循环式调度方案，然后采用快速汉密尔顿回路算法进行物理映射。通过
各个仿真平台仿真其计算时间，计算单位为毫秒。所有不同硬件平台的计算时
