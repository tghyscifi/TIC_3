根据上面表格数据可得：单个 core 在 128 KB 存储容量、128 个 MAC 下，
MAC 的结构模式应当设计为 4×4×8。 单个core 在 256 KB 存储容量，128 个 MAC
下，MAC 的结构当选 4×2×16。单个 core 在 512 KB 存储容量，128 个 MAC 下
其结构当选 4×32。但是对于不同的网络由于网络尺寸不同，因此 MAC 的最优结
构都是不同的。天机 X 芯片设计单个 core 在 128 KB 存储容量，128 个 MAC 下，

对于天机 X 芯片其 MAC 结构应该设计为 4×4×8。当单个 core 的 MAC 数目和存
储器容量确定的时候，MAC 的结构可以确定下来。
