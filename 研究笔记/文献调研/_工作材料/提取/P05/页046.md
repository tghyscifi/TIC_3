1.6.2 研究目标与内容 
本论文的研究目标 围绕提升芯片的计算效率进而 研究支持高效映射策略的类
脑计算架构。本论文的研究内容主要分为三部分： 对映射调度策略进行研究进而降
低计算延迟；对调度策略下产生的传输负荷进行 物理映射研究进而 优化降低传输
延迟；对芯片架构自身优化以 提高芯片自身的映射效率并提高芯片本身的计算速
度。 
本文基于清华大学类脑计算中心开发的天机 X1 类脑计算芯片进行时空映射
理论研究。天机 X1 是 2022 年发布的一款类脑计算芯片，它采取去中心化、核粒
度存算一体的分布式众核架构。核与核之间采用 2D mesh 的互联结构。该芯片与
天机第二代芯片一样同时支撑 ANN 和 SNN 以及二者的混合模型 HNN。 与第二代
天机芯片的一个 core 只能完成一种执行命令任务不同，天机芯片的每一个 core 能
执行所有的原语指令，属于具有细粒度功能的时空混合粒度的计算芯片。 
在映射过程中，基于每个 core 的有限的存算资源，首先进行被计算任务的资
源调度研究。 通过资源调度研究，寻找最优的时空资源调度理论和策略。其次，在
任务资源的调度研究中具体 可分为单任务的资源调度和多任务资源调度 的研究。
再次，基于已知的调度研究进行物理映射研究。 通过物理映射研究，寻找最优的路
由功耗和最低延迟的物理映射部署策略。最终，基于映射理论进而对芯片进行优化
设计从而使硬件系统其支持最优映射模型。论文章节安排如下： 
第 1 章首先介绍人工智能发展的历史、类脑计算芯片的特性。其次分别介绍
了人工神经网络、 脉冲神经网络的发展以及人工智能芯片的发展。 针对神经网络在
硬件平台的映射研究状况，分别介绍了存算分离集中式众核的映射、 存算一体分布
式众核架构的映射。 针对典型双脑驱动类脑计算芯片天机系列芯片， 介绍了通用类
脑计算软件的研究。通用类脑计算软件对类脑芯片的使用提供了便利性和时效性，
但是对于双脑驱动类脑计算芯片 在映射器的资源调度方面和代码生成器方面的物
理映射仍需要进一步研究， 
第 2 章介绍众核架构芯片的映射原理。为了使映射在时间尺度上能够解耦，
采用动态规划的知识并结合马尔可夫链的增量独立原则将映射阶段进行划分。分
解为网络分层分组、 时空资源调度、 物理映射三个阶段。 并对于网络分层分组阶段
提出时空密度映射， 为了降低不同core 簇之间的时空密度不均衡性相应构建了 core
簇任务的共享数据方法、不均匀拆分方法、 任务资源匹配方法等。最后，基于天机
X1 芯片的映射平台进行大量的实验研究。 
第 3 章介绍单个 core 簇计算任务的时空资源调度。建立 4D 映射调度的非循
环模型，对权重复用型、输入复用型、行流水三种映射到时间复杂度和空间复杂度
