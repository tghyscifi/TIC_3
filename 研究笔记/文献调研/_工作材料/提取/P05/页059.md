2.3.2 均衡时空密度的不均匀拆分方法与实验 
不同于本人硕士阶段的均匀拆分，本文提出一种新的拆分方法即不均匀拆
分，该方法旨在均衡不同 core 簇之间的时空密度。 所谓不均匀拆分，即对一个
计算任务，所分配的 core 簇每个 core 内部的所分配的数据量和计算量并不一
致。 例如对于ResNet 50 来说，假定对于计算量为 438 MOPs 的 Block 3 和 Block 
4 以及 Block 6～8、10～14 每个 Block 分配任务为 28 个 core。为了均衡，对
于计算量为 592 MOPs 的 Block 5、Block 9 根据等比例分配 core 簇，应该分配
38 个 core，为方便拆分则分配 40 个 core。其中，Block 5 的尺寸参数如下表：
