2.5 本章小结 
本章对映射过程进行划分 ，基于马尔可夫增量独立过程 将映射过程划分为三
个阶段：网络任务分组阶段(时空密度调整阶段)；任务的时空资源调度阶段；逻辑
core 到物理 core 的物理映射阶段。本章基于动态规划的最优原理，指出映射的各
个阶段的最优的决策 所组成的策略是最优映射策略。这为最优映射提供了研究分
析方法。 
针对映射的第一个阶段(网络任务分组阶段)本章提出了时空密度映射理论。 并
且基于映射原理和时空映射密度理论，本文提出了精细时空密度映射方法、均衡时
空密度数据共享的映射方法 、不均匀拆分映射方法 旨在降低不同组之间的时空密
度的方差， 进而提高不同组之间时空的均衡性。 为了对以上的各种方法进行实验验
证，选取具有时空粒度的众核架构的天机 X 硬件平台，最终，通过实验证明相较
于逐层的流水式映射，多层耦合的精细时空密度映射方法可使硬件的计算 速度提
升 1.86 倍。 
此外，本章完成了对天机 X 硬件平台支持富模型神经元的验证工作。基于映
射原理和精细时空密度映射，选取基于 Izhikevich 的模型的手写体数字识别算法在
天机 X 芯片进行映射仿真，其计算结果显示天机 X 对于手写体数字识别的精度可
达 95%。映射调度中消耗 35 个 core 资源，实现对双层 Izhikevich 的模型计算速度
