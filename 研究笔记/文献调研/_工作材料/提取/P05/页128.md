4.4 基于循环式映射的单网络物理映射 
在本论文的第三章的第四小节中提出一种循环式资源调度 ，在循环式资源调
度中，core 簇之间每个 core 形成一个闭环的回路。沿着闭环的回路，计算过程中
或是传输权重数据，或是传输输入图像数据。 下面将讲述基于循环式资源调度下的
物理映射。 
4.4.1 单 core 簇的汉密尔顿回路映射 
由于循环式资源调度所形成的闭环回路 其实质就是一条汉密尔顿回路。 天机
系列芯片仅支持水平和垂直方向的路由，不支持斜边方向的路由。 因此当汉密尔顿
回路的节点数目是偶数的时候可以在 2D 平面上找到。 由于拓扑的灵活性，将汉密
尔顿回路拓扑在一个不固定的 2D 平面上，存在多条回路。如下图所示：

从上图 4.27 中可以看出当节点为 16 的时候，存在很多条 2D 方形下的汉密尔

形区域中可以快速找到一条汉密尔顿回路。算法如下： 
在方形区域内寻找一条单个节点(core)传输距离为 1 的汉密尔顿回路，传输的
总距离为 core 的数目，该方形区域灵活变换。 方形区域的面积等于节点(算 core 数
目)。设顶点排列成 m 行 n 列的阵列，则根据 m、n 值可分以下三种情况讨论： 
(1) m = 1，n = 1，此时汉密尔顿回路为一个自环，不需要路由。 
(2) m 和 n 中有一个为 1，另一个不为 1，或者 m、n 均为奇数，此时汉密
尔顿回路不存在，仅存在欧拉回路。
