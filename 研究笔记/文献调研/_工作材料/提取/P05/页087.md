3.3.3 四维输出数据向量排布 
计算完毕后对每个 core 产生的结果数据按向量进行编号，以便按照一定的次
序聚合成整个图像的原貌。数据的聚合相对于数据的分配、拆分的逆过程。 经计算
完毕后，图像的输入深度相当于被拆分成 N 分，每个 Out 向量的长度为 Oz/N。与
输入图像拆分相似。该算法需要三大步，第一步：找出 0 号 core 的所有 Out 向量
排布，x 表示向量在未拆分前所处图像横向坐标，y 表示向量在未拆分前所处图像
纵向坐标对应代码为： 
 for x in range(Ox): 
 for y in range(Oy): 
      num = N(yOx + x) 
  vector_Out.append(num) 
第二步： 找出其他所有core 的第一个向量的所在存储区间的编号对应代码为： 
Start=OyFxNi+OxNj+n 
第三步：0 号 core 所有向量编号对应加上其他 core 第一个向量的编号，通过
以上三步便得到该 core 内部所有向量。通过寻找到每个 core 的首向量的初始位置
进而得到所有 core 内部向量。Core 内部向量均是按照从小到大顺序排列在 core 内
部的存储空间中。对应代码为
