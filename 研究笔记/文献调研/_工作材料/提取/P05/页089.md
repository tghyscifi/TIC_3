3.4.1 闭环回路循环计算数学原理 
为了能够满足公式(3-33)，本文提出循环式资源调度。 如下图3.14 所示：输入
图像上所拆分的份数等于总的所分配的 core 的数目，并且权重所拆分的份数等于
所分配 core 所有的数目。以分配四个 core 为例，循环转动输入数据，其计算原理
如下图所示： 
 
图 3.14 闭环式回路循环计算原理 
图中 A1～A4 表示神经网络的输入图像，W1～W4 表示神经网络的权重。T 表
示计算阶段。第一个计算阶段 T0 每个 core 内输入图像数据与自己的权重进行卷积
计算。T0 计算完毕后开始对数据进行循环发送。1 号 core 将 IA1 发 2 号，2 号将
IA2 发 3 号，3 号将 IA3 发 4 号，4 号将 IA4 发 1 号。这样形成一个闭环链。第二
个计算阶段在 T1 计算阶段，编号为 1 的 core 内部 W1 与 IA4 数据进行计算，编号
2 的 core 内部 W2 与 IA1 进行数据计算，编号 3 的 core 内部 W3 与 IA2 进行数据
计算。编号 4 的 core 内部 W4 与 IA3 进行数据计算。计算完毕后 1 号 core 将 IA4
发 2 号，2 号将 IA1 发 3 号，3 号将 IA2 发 4 号，4 号将 IA3 发 1 号。第三个计算
阶段在 T2 计算阶段，编号为 1 的 core 内部 W1 与 IA3 数据进行计算，编号 2 的
core 内部 W2 与 IA4 进行数据计算； 编号3 的 core 内部 W3 与 IA1 进行数据计算。
编号 4 号的 core 内部 W4 与 IA2 进行数据计算。计算完毕后 1 号的 core 将 IA3 发
2 号，2 号将 IA4 发 3 号，3 号将 IA1 发 4 号，4 号将 IA2 发 1 号。第四个计算阶
段在 T3 计算阶段，编号 1 的 core 内部 W1 与 IA2 数据进行计算。编号 2 的 core
内部 W2 与 IA3 进行数据计算；编号 3 的 core 内部 W3 与 IA4 进行数据计算。编
号 4 的 core 内部 W4 与 IA1 进行数据计算。以上计算过程其数学原理可以用公式
(3-41)或者(3-42)所示：
