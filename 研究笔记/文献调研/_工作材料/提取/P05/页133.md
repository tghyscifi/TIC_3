表 4.1 天机 X 路由速度性能测试实例 
从实验数据中可以证明传输的时间与数据容量成线性正比。 芯片在设计时，路
由单元 Router 的处理速度为 8 B/clc，Soma 单元从其他存储器的取址速度为 16 
B/clc。 最后通过实验验证得到，Soma 单元和路由单元流水发送并搬回的处理速度
为 2.29 B/clc，这与理论测算的速度不同。其次，基于天机芯片平台对跨 core 延迟
进行实验评估。由于天机 X 架构在 2D 结构设计长度为 16、宽度为 10，因此最大
跨 core 数目只能为 8。选择收发数据容量为 49 KB，沿单一的一个方向延迟实验测
试结果如下表 4.2 所示：
