第二代天机芯片在资源调度方面上基于每个 core 的存储空间对网络按 core 的
功能任务进行全展开，权重采用横向协作拓展模式；在 core 间数据传输上采用多
播的方法进行数据复制并行流式映射。对 reshape 维度调整，向量矩阵乘法，向量
加法，各个任务进行全展开映射到对应的功能 core 的端到端映射[135]。 并采用相位
时序精细化配置实现时分复用。 
对于异构网络的映射，采用乒乓模式使 ANNs 和 SNNs 进行混合转换。例如轴
突和胞体在二级求部分和时，当第一级为轴突处于 ANNs 模式，胞体处于 SNNs 模
式；第二级则轴突处于 SNNs 模式树突处于 ANNs 模式。除此之外，天机芯片资源
调度 采 取 对 节 点 网 络 进 行拆分和组合 ， 对 输 入 图 像 进 行 分 割 和 复 制。 基于
Kernighan-Lin(KL)散度算法使图像在拆分时候产生最小的交叠[136][137]，在物理部署
上将大量数据相互传输的 core 进行紧密排布。针对在映射过程中部分和求解的精
度损失问题，天机芯片采用了粗粒度和细粒度的混合映射方案[138]，进而支持多种
异构网络在同一块芯片内的并行协同工作。 
2020 年，吴楠[139]基于与天机 X 芯片类似的硬件架构上进行映射仿真。 对于多
层任务的映射基于逐层拆分进行流水，不考虑层与层之间的时空资源不平衡性。 对
于单个层内部采用输入深度和输出深度进行均匀拆分，进而配置硬件的存算资源。
对于物理部署采用机器学习算法，相比于顺序映射，随机映射、 模拟退火算法，机
器学习算法的路由延迟分别可降低 67.4%，51.7%和 23.2%。通过优化路由延迟时
间无法测算芯片最终映射计算效率。 
针对物理映射中的路由死锁检测问题、路由功耗优化问题、片内路由延迟问题，
清华大学类脑计算中心 均做了大量的研究。 赵琦采用模拟退火算法解决死锁问题
并降低物理路由延迟，通过模拟退火算法确定每一个 core 的物理位置，使片间传
输量最小[140]。该模拟退火算法与顺序映射进行比较，其结果显示与之字形和顺序
路由相比其路由延迟和功耗平均降低 50%左右。宋昆对于死锁的检测采用基于网
络流的算法和目标控制方法； 对动态图的路由过程进行建模，深度优先搜索的方法
快速判断死锁问题[141]，并通过遗传算法提高死锁的检测率。杨玉宽[142]在模拟退火
算法的基础上提出了区域局部的模拟退火算法，该算法旨在降低 NP 问题的搜索空
间下快速对死锁进行检测，而且优化路由延迟。针对 ResNet 18 的物理映射其优化
前后对比路由延迟时间降低 8.7%，针对 ResNet 50 的物理映射其优化前后对比路
由延迟时间降低 21.58%。该算法的死锁检测率高达 99.85%，对于 ResNet 34 的在
4 个芯片的物理核布局优化，其搜索空间分别为原传统算法的 28.51%、29.55%、
