基于空间流水映射的缺点是如图中右侧所示，计算时间以最长的时间为准，不同簇

图 1.17 不同架构映射现状对比图 
不同于加速器架构的时间流水映射 以及神经形态芯片的流水映射，目前类脑
芯片开始采用时空流水映射。由于众多机构所研发的类脑芯片其架构差异很大，因
此一个通用的类脑软件系统对于算法的部署极其重要，且对于部署的便利性，时效
性，硬件发挥效率都有着极其重要意义。众核架构采用 2D Mesh 的阵列其并行度
高，传输带宽大，扩展性强。目前众核架构的芯片算力发挥效率大多不高，很多机
构并未给出具体的数据。根据查阅文献的数据推算，以 ResNet 50 为例，英伟达的
Simba 的计算效率不足 15.8%，其他众核架构映射文献避重就轻，在计算效率方面
提供有效数据较少。天机 X 芯片对于 MLP 由于仅仅开一组 MAC，因此算力效率
发挥为 25%；对于 ResNet 50 未作物理映射优化的算力发挥效率 12.69%。因此类
脑众核架构芯片在效率提升方面还有着极大的发挥空间。 
因此，对于分布式众核架构在相同粒度限时空资源的 core 上部署任意规模的
时空资源的网络面临着许多挑战，主要的体现在三个层面： 任务的时空资源不均衡
性与同构 core 时空资源均衡性的矛盾，即任务时空资源调度所引起的计算延迟大
的问题；从任务时空资源调度到 2D Mesh 众核架构的物理部署 NP 难问题所导致
路由延迟带来传输延迟大的问题；芯片自身的算力单元结构与存储空间设计与 计
算时间和映射效率的问题。针对这三个层面的问题所延伸的具体问题也是较多的，
例如多精度计算中不同精度计算 尤其部分和数据计算 带来的映射效率问题；多任
务之间物理部署的空间资源利用率与吞吐率 之间的代价模型；不同时空资源调度
策略与不同物理部署方案之间对应匹配模型等等。
