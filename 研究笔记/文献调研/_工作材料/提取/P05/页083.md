经过拆分后每一个向量长度等于输入深度 Fz 除以输入深度拆分组数 M，因此
向量长度为 Fz/M，该 Fz/M 向量连续占存硬件多个地址。例如 Fz/M=128，则连续
占芯片内存的 4 个地址模块；Fz/M=256，则连续占 8 个单位地址。计算任务的数
据按照向量长度 Fz/M 为最小尺寸则连续存储 MIJ 个向量，对每个向量进行编号
如上图 3.7 的右边所示。这里 J 表示图像宽度被拆分的组数，I 表示图像高度被拆
分的组数。 显然，拆分后的每个 core 内部数据的宽度(Div_Fx)为 Fx/J，高度(Div_Fy)
为 Fy/I(Div 是英文单词 Division 前缀)。经过拆分后每个 core 内部存储的数据向量
个数为拆分图像宽度与高度乘积即 Div_FxDiv_Fy。 将图中的向量编号按照数学规
律抽取至每个 core 中。 
如下图 3.8 所示：0 号 core 存储 4 个向量，向量按照编号的大小从小到大依次
连续摆放在 core 内部的存储单元中。将这所有的向量按照一定规律准确分布到每
个 core 中。第一步：找出 0 号 core 的所有向量排布，设 x 表示向量在未拆分前所
处图像横向坐标，y 表示向量在未拆分前所处图像纵向坐标。对应算法的伪代码为：
