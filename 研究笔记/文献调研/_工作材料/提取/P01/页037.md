1.2.2.1  软件工具链 
如图 1-21 所示，不同的神经形态芯片均有各自的软件工具链以支撑应用生态，
但总体来说相对较为独立。TrueNorth 芯片的 corelet 编程语言为其提供了一定程度
的功能抽象，将神经网络描述为众多功能核之间的连接关系，经过优化布局之后部
署到芯片上运行，并通过具有完全对应关系的仿真器进行功能仿真和验证 [149]。
SpiNNaker 平台和 BrainScaleS 平台均采用了源自于计算神经学的脉冲神经网络描
述语言 PyNN[153]作为应用开发语言。SpiNNaker 通过 sPyNNaker 软件[154]将基于
PyNN 语言描述的脉冲神经网络 解析并部署在其 上通过事件驱动的程序执行方式
运行。BrainScaleS 也通过相应的软件映射部署过程完成神经元和突触连接的分配
以及对于模拟电路参数的校准和调谐[137]。但是 PyNN 本身是针对作为神经学实验
补充的计算机模拟方面的需求开发的，并不完全适于类脑智能应用的描述与开发。
NeuroGrid[123]通过用户界面、 硬件抽象层和驱动程序三层的软件结构将用户想要模
拟的脉冲神经网路模型转换为电路中的偏置电流和路由连接关系。Loihi 芯片开发
了自定义的 Python API 接口以及用于在 Loihi 上构建和执行脉冲神经网络的编译
器和运行库[152]，进而 Nengo 神经模拟器的 Python 包允许用户在不访问硬件的情
况下研究 Loihi 上脉冲网络的实现。这些软件工具链均只支持脉冲神经网络直接部
署执行，对于人工神经网络的支持有限。
