(2) Regarding the lack of hardware d eployment scheme for hybrid neural network 
(HNN) models, this work proposes a mapping framework and hardware platform for the 
end-to-end implementation of HNN models on the cross -paradigm neuromorphic chip. 
The proposed solution provides good support for t he multimodal data interaction and 
multiple networks’ parallel collaboration in the hybrid models. Specifically, typical signal 
conversion methods  are summarized and their hardware configuration scheme  is 
established. On this basis , a global timing adjustment mechanism matches the different 
execution periods between heterogeneous modules. A modular external interface solution 
solves the system scheduling and data distribution problems in the parallel multi-network 
cooperation tasks. 
(3) Regarding the problems of poor programmability and low resource utilization in 
traditional neuromorphic chips dealing with complex and diverse network models , this 
work designs and implements a new generation and spatiotemporal multi -granularity 
brain-inspired chip, Tianjic X1. It has coarse-grained primitive instructions and supports 
asynchronous timing cluster grouping among FCores, which realizes the spatiotemporal 
multi-granularity optimization of the neural network execution. By introducing the stack 
sequential execution of multiple primitives to the FCore, its independent programmability 
is greatly improved. The multi -level asynchronous sequential cluster grouping 
mechanism enhances the load balance between FCores, and the efficient and compact 
execution of single network and asynchronous information interaction between multiple 
networks are realized. 
In this work, the method of hardware-software co-optimization provides a new way 
for the development of a general brain-inspired computing platform. 
 
Key words: brain-inspired computing; neuromorphic chips; cross-paradigm integration; 
network mapping; spatiotemporal execution
