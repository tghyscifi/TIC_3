1.2.2.2  代表性芯片 
从发展过程来讲， 自加州理工学院的Carver Mead 教授 1989 年在 《Analog VLSI 
and Neural Systems》一书中提出用专用电路实现脉冲神经网络的“类脑神经形态工
程”[129]概念之后， 神经形态芯片的发展可以分为侧重脑仿真模拟和侧重高效智能计
算两个方向。 
在早期的神经形态芯片研究中，神经形态芯片的研究的更侧重 通过程序级或
者电路级的创新，搭建可以支撑脑科学研究的大规模的脉冲神经网络仿真平台。主
要有搭建低功耗的脉冲神经网络超级计算平台以及延续 Carver Mead 教授的大规
模数模混合电路系统两种方法。前者的代表性工作为英国曼彻斯特大学 Steve 
Furber 牵头研发 SpiNNaker 平台[118, 125, 130 -134]，后者的代表性工作有海德堡大学
Karlheinz Meier 领导开发的 BrainScaleS 平台[135-140]和斯坦福大学 Kwabena Boahen
教授领导开发的 NeuroGrid 平台[123, 141-143]。 
SpiNNaker：作为欧盟 “脑计划 ”（Human Brain Project ，HBP）的一部分，
SpiNNaker 旨在建立实时仿真大规模脉冲神经网络的大规模并行类脑计算平台， 从
而支持 10 亿神经元和 1 万亿突触连接规模的连接。它采用了类似超级计算机的构
建思路， 通过多个层级的通信互联将经过特殊优化的ARM9 处理器内核连接起来，
并运行具有事件触发的消息处理机制的神经元仿真程序，在没有脉冲事件到来时
处理器处理低功耗状态。如图 1-15 所示，每个 SpiNNaker 芯片是一个包括 18 个定
点的 ARM968 E-S 处理器核、 一个定制的路由接口电路以及128MB 片外的 DRAM
的 MPSoc（Multi-Processor System on Chip） ， 并采用GALS（Globally Asynchronous 
Locally Synchronous）的时序同步机制。定制的路由接口电路支持通过丰富路由方
式的自定义协议和其他芯片进行通信。芯片采用 130nm CMOS 工艺制造，尺寸为
102mm2，在运行频率为 180MHz 时功耗约为 1W。

了自定义的 Python API 接口以及用于在 Loihi 上构建和执行脉冲神经网络的编译
器和运行库[152]，进而 Nengo 神经模拟器的 Python 包允许用户在不访问硬件的情
况下研究 Loihi 上脉冲网络的实现。这些软件工具链均只支持脉冲神经网络直接部

1.2.3  深度学习加速器 
除了神经形态芯片之外， 还有一类面向于高速、 低功耗地运行人工神经网络的
深度学习加速器芯片。深度学习加速器芯片主要 为了解决通用处理器执行人工神
经网络模型效率低的问题，相较于神经形态芯片构建大规模去中心化、 任意互联的
智能处理系统的思想，深度学习加速器更侧重于解决如何在资源有限的情况下尽
可能地通过优化计算数据流和存储访问机制来提高芯片的有效利用率。 因此， 加速
器中的一些设计方案和思想对于高效跨范式类脑计算芯片 的设计也有着重要的参
考意义。 
对于深度学习加速器，本文主要关注于 在不改变模型本身的情况下通过仅优
化硬件设计提升加速芯片性能 的纯硬件优化设计方法。这种方法 主要通过设计并
行度高的计算单元、 本地性好的缓存体系、 提升数据的片上复用率以降低外存带宽
需求等硬件优化手段来提高芯片的执行效率。

计为三级流水线的方式提高计算吞吐率。 在进行运算时， 网络的模型参数和输入数
据会被依次加载到 SB 和 NBin 中，经过 NFU 的运算并被写回到 NBout 中。通过循
环调用的方式使得其对于模型灵活性和模型尺寸上的支持性有了显著的提高。在
此基础上，DaDianNao 芯片[155]针对于服务器端的高性能计算场景，通过集成片上
eDRAM 的方式减少片外存储访问所带来的延迟， 并将权重存储单元分布至各个计
算单元块内部以获得较高的存储本地性 以及 更好的片上 eDRAM 访问性能。
ShiDianNao 芯片[156]针对卷积神经网络算法应用部署优化， 利用卷积神经网络中权
重共享的特点，将权重全部存储在芯片中的 SRAM 中，并通过二维计算单元阵列
之间数据传输共享来降低 SRAM 的访问带宽需求。PuDianNao 芯片[157]进一步将优
化目标扩展到多种机器学习算法， 通过引入具有不同数据复用距离的冷缓存区和
热缓冲区来优化数据重用，减少片外访存开销。同时在计算单元的设计上，
PuDianNao 通过为计算学习算法定制的 MLU（Machine Learning Unit） 加用于常规
计算控制任务的 ALU（Arithmetic Logic Unit ）组成的基本单元来提高片上的处理
能力。 在这些基础上，DianNao 系列还提出了针对于人工神经网络应用的领域内特
性指令集架构 Cambricon[158]，针对于在神经网络中高频的向量计算、矩阵计算以
