1.2.3.3  基于众核/多核架构的加速器 
随着深层网络模型计算量和存储量的增加， 深度学习加速器也开始借鉴神经
形态芯片的思想，增加片上分布式的存储和计算单元，构成片上众核 /多核结构。
Wave Computing 的 DPU（Dataflow Processing Unit）芯片[172]采用粗粒度可重构阵
列（Coarse-Grained Reconfigurable Architecture）的数据流处理架构，每个 DPU 内
集成 32×32 个 cluster 并分割成 24 个区域。每个区域包含 32 或 64 个 Cluster，称
为一个 Compute Machine。每个 Compute Machine 拥有独立的 128-bit 的 AXI 总线
接口。DPU 通过一个基于 AXI4 的网络，实现与存储器、输入输出设备的 24 个接
口互通。 每个Cluster 基于全定制版图实现，其内部包含 8 个算术单元和 16 个计算
单元。DPU 使用了异步逻辑实现基本计算单元的设计，没有同步时钟信号，计算
单元只要收到操作数，就触发计算并得到结果。结合编译器，可以对 Cluster 的计
算以及数据在 cluster 之间的传输进行调度，从而实现对于多种算法的支撑。 
Graphcore 公司发布的 IPU（Intelligence Processing Unit ）芯片[173]，同样采用
了同构多核的架构，每个芯片上集成了 1216 个独立的处理器，可以同时支持训练
和推理任务。这些分布式的处理器之间可以实现片上的任意互联通信，并采用了
“批量同步并行”（Bulk Synchronous Parallel，BSP）的模型来实现处理器之间的
同步计算。在这种机制中， 芯片的基本操作可以分为三个：1)本地计算阶段， 每个
处理器对存储在本地的数据进行计算， 更新计算结果；2)同步等待阶段， 等待所有
处理器中的进行都执行到同步点；3)栅栏同步阶段， 等待所有处理器之间的数据交
换完成。同时，芯片集成了 300MB 的片上分布式的 SRAM，并可以通过高速的片
间互联接口进行扩展互联，从而可以避免外部 DRAM 的使用。

第2章  跨范式融合的神经形态芯片 
2.1  本章引言 
根据第 1 章的叙述可知，当前深度学习加速器和神经形态芯片二者分离的架
构使得它们都无法同时支持以 ANNs 为代表的深度学习和以 SNNs 为代表的神经
形态计算， 这限制了二者跨范式融合趋势的进一步发展。因此， 首先要实现在同一
硬件平台上对两种计算范式的同时支持。 
而 ANNs 和 SNNs 在信息表示、计算原理和存储组织方面存在着显著的差异，
为设计和实现能够同时支持两种计算范式的硬件平台带来了极大的挑战。在这种
情况下，简单的将目前分立的计算平台集成组合在一起是行不通的， 这种方法在实
际中存在灵活性低、 利用率低以及可扩展性差的缺点：首先， 这种异构集成系统在
资源分配上缺乏灵活性， 无法根据工作负载的变化而动态地调整负责 ANN 计算和
SNN 计算的单元的比例；其次，这种集成系统对于面积和功耗的利用都不高效，
尤其是在处理单一范式模型时， 会导致总体利用率很低； 最后， 在处理跨范式混合
模型时，这种异构集成系统会需要额外的 转换单元来实现两个子系统之间的信息
交互，带来额外的成本降低效率。 
针对这一问题， 本章提出了基于跨范式融合功能核的众核芯片架构， 旨在通过
可以在 ANN 和 SNN 模式（以及混合模式）之间灵活重配置的统一结构功能核支
撑两种范式在同一平台上的计算。 高度的资源共享和工作模式可重构性可以赋予
这种架构极大的灵活性， 使得它具有可调的ANN-SNN 比例，同时可以动态优化资
源分配， 有效地应对多种算法模型。具体而言， 实现这样的一个跨范式融合架构，
首先要建立支撑两种计算范式的统一模型描述框架，采用尽可能低的成本来融合
不同范式的神经网络计算； 其次要在具体的模块和电路设计中实现复用性，实现最
大化的面积和功耗利用效率以及高的吞吐率； 此外， 还要考虑模型映射的灵活性，
在网络模型的映射部署过程中实现性能和资源开销之间的权衡。 
在后续章节中将遵循 “架构模型—模块设计—网络映射” 的思路， 对上述问题
进行研究和解决：
