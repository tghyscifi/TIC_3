# 参数配置

## 即时原语

1. 发送即时原语请求方的 `router.add_instant_pi()`

   ```python
   router.add_instant_pi(
    PI_addr_offset=0,  # 前面的即时原语原语数之和
                       # 例如：如果前面有一个即时原语
                       # 即时原语有soma1和router
                       # 则PI_addr_offset=2 
    # 需要哪几个原语则配置哪几个
    A_valid=0, S1_valid=1, R_valid=1, S2_valid=0,
    X=0, Y=1, Q=1)
   )
   ```

## 特殊技巧

1. 循环权重的时候需要循环对应的偏置
2. 输入通道拆分，求部分和时避免重复加偏置
