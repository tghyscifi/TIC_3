3.4 异步相位组之间的数据交换
由于各相位组是由各自的相位控制器独立的运行产生，因此不同的相位组之间在 Phase
的运行上是异步的。当不同的相位组之间需要进行数据传输时，为了保证数据的完整性，通
过即时原语的“发送-应答-传输”机制来进行跨相位组的数据传输。
以图 3- 4 为例，core 0、core1、core2 属于 Phase_group1，core3、core4、core5 属于
Phase_group2，Phase_group1 的 3 个 core 需要给 Phase_group2 的 3 个 core 发送数据。此时，
配置 core0 的路由原语参数为需要发送一条即时原语包，需要收到一条即时原语应答；core1
和 core2 不需要发送即时原语，但是需要收到即时原语应答；core2 配置为需要返回即时原语
应答。
图 3- 4 即时原语 “发送-应答-传输”机制传输数据示意图
Phase_group1 和 Phase_group2 之间的数据传输可以总结为如下几个过程：
1. 即时原语的跨组发送：当对应 Phase 开始之后，core0 向 core3 发送一条即时原语包，
此时 core0~core2 都等待接收到即时原语应答之后再开始发送数据；
2. 即时原语的接收和组内多播：core3 收到即时原语之后，将即时原语索引存储到
controller 的即时原语 FIFO 中，同时将即时原语包多播给 core4，并将等待即时原语
多播应答计数器加 1；core4 执行同样的接收存储操作，将即时原语包多播给 core5；
core5 执行相同的接收存储操作；
