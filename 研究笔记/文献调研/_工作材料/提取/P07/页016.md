4. Controller Unit
4.1 模块概述及结构
Core 的运行由 Controller Unit，即 PI 处理器（PI processor）控制管理。Controller 负责根
据预置的静态原语组堆栈信息，调用 Axon、Soma 和 Router 模块；Controller 也负责响应和处
理通过路由接受到的即时原语执行请求信息。Controller 中存储原语执行堆栈的索引信息。根
据索引信息，Controller 生成待执行的原语在 Memory 中的地址指针，并发送给 Axon、Soma
和 Router。各处理器收到原语启动信号后，到相应地址中读取原语参数、执行相应操作并将
执行状态反馈给 Controller。
