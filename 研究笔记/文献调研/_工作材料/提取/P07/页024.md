6.2 控制逻辑原语 0：PIC=00 空原语

该原语的执行模式为，收到 PI _A_en 后，将 A_idle 状态信号置零，2 个时钟后再将 A_idle

6.3 控制逻辑原语 1：PIC=0x41（CNN0）
6.3.1 原语功能简述
该卷积原语对应的是对具有较大输入通道数（FM 数>8）输入图像的卷积操作。原语支
持与偏置向量 Bias 作累加。支持对图像进行 padding 处理，可以设置四个方向的 padding 参
数（默认是 0）；支持膨胀卷积，可以设置膨胀系数 Ex、Ey（系数为 1 即为常规卷积，参数
默认是 0）。
6.3.2 原语执行的算法流程
CNN0 模式用以下六级循环 L0—L5 完成含有三个维度（图像宽度 Px、图像高度 Py、输
入通道数 M）的向量 X 和四个维度（卷积核宽度 Kx、卷积核高度 Ky、通道数 M、卷积核个
数 N）的权重 W 的卷积运算。
1 for Oy = 0 : Oy_num ( Output fmap height )
2 for Ox = 0 : Ox_num ( Output fmap width )
3 for n = 0 : n_num ( Output channel)
Out_FM [Oy][Ox][ n ] = Bias [ n ] (or 0)
4 for Kx = 0 : Kx_num ( Filter width )
5 for Ky = 0 : Ky_num ( Filter height )
6 for m = 0 : m_num ( Input channel )
Out_FM [ Oy ][ Ox ][ n ] +=
Input_FM [Py_cnt][Px_cnt][m] × Weight [Ky][Kx][m][n]
