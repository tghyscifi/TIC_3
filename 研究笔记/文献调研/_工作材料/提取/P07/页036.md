8. Soma Processor
8.1 模块概述及结构
Soma 模块用于从 Memory 中读取数据，进行数据比较、数据搬运整理和神经元的非线性
变换操作。主要包括比较（CMP）、数据整理（Move）、ANN 激活函数（LUT）和 SNN 激活
函数（LIF+）等操作。神经元处理器可以访问 Memory 模块中用于数据收发缓存的空间，从
而参与 Core 间数据收发。神经元处理器（Soma）可以将待发送数据搬运到发送缓存区或者
将接收缓存区中存储的数据搬运出来。
