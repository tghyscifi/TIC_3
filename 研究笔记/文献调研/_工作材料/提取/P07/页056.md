10.3.1 Serdes 帧格式
每帧固定长度 128 位，最高位 M 标志位用于标识包的类型，是配置调试包还是跨片数据
包， M=00 为配置调试包，片内数据传输时使用专用的配置线；当 M=11 时是跨片数据包，
到片内时数据传输使用 NOC 网络。
 跨片数据包
其中，Payload 为 Core 间路由包（96bit）。
 写命令包：
M=00 F=0 RW=1 Rsv Chip ID B X Y A L Ver Rsv Data CRC
2b 1b 1b 4b 4b 1b 4b 4b 16b 16b 16b 11b 32b 16b
 写数据包：
M=00 F=1 RW=1 Rsv Chip ID Rsv Data CRC
2b 1b 1b 4b 4b 4b 96b 16b
 读命令包：
M=00 F=0 RW=0 Rsv Chip ID B X Y A L Ver Rsv Rsv CRC
2b 1b 1b 4b 4b 1b 4b 4b 16b 16b 16b 11b 32b 16b
 读数据包：
M=00 F=1 RW=0 Rsv Chip ID Rsv Data CRC
2b 1b 1b 4b 4b 4b 96b 16b
F：F=0, 配置命令包； F=1，配置纯数据包
RW：RW=0，读数据；RW=1，写数据。
Chip ID：由发送逻辑自动附加，由接收逻辑自动解除，用于配置 Chip 选择，具体参考第 10.3.3
节跳片配置方法。
B：Bank select。B=0, chip 寄存器； B=1，core 地址访问。
X，Y：选择 chip 内 256 个 core，参考 1.2 Block Diagram。
A：16bit core 地址。
M=11 CoreID Rsv Payload CRC
2b 4b 10b 96b 16b
