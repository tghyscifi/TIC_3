4.3 Controller 的控制逻辑执行调度
4.3.1 原语执行调度
每个 Core 有一个 5bit 相位控制器选择寄存器 Psel[i]。用于从 32 组相位控制器输出的
pck_grp[X]中选择一路作为本 core 的相位计算触发信号，而该组相位控制器选通的节拍触发
信号 sck_grp[X]亦同时成为本 core 的节拍触发信号。
在每一个 Phase 中，P_ck 触发后，功能核状态信号 Core_finish 被拉低，Core 内开始执行
新一组原语运算。Controller 判断即时原语组索引 FIFO 中是否存在需要执行的即时原语组，
如果满足即时原语组执行条件，执行 FIFO 中的一条即时原语组；否则，按照顺序执行一条
静态原语组。Controller 依次检索所执行原语组的 Axon、Soma1 和 Router 原语索引信息。如
果对应的原语请求不为空，则生成原语参数在 Memory 中的地址和读请求发送给对应执行单
元。Axon-Dendrite、Soma、Router 模块在接收到 PI 原语的存储地址，并从 Memory 中读取完
参数之后，会将各自对应的 idle 信号拉低（Router 包括 Send_idle 和 Receive_idle）；当执行完
各自操作以后或不需要执行原语时，idle 信号为高。在 Soma 执行完 Soma1 原语 S_idle 为高
或者不需要执行原语时，等待 Router 的 Receive_idle 为高，则 Soma 会根据 S2_valid 是否为 1
继续执行 Soma2 原语。之后在各个模块执行完静态原语之后，会将各自对应的 A_idle、S_idle
和 Send_idle 和 Receive_idle 信号由低转高。等到对应各模块的 A_idle、S_idle 和 Send_idle 和
Receive_idle 信号都为由低转高后，会拉低 Core_busy 状态信号，表示完成当前 Phase 操作完
成，此时 Core 可以进入低功耗模式。
4.3.2 与各模块间的交互
由于在 Tianjic X1 中，在每一个 Phase，Axon-Dendrite、Soma 和 Router 会出现某个模块
不工作的情况，为保证各个模块的之间的并行流水特性及不受单一模块是否开启的影响，采
用每个模块将自身运行状态反馈给 Control Unit，Control 根据内部逻辑产生各模块的工作使能
信号来保证各模块可以实现较好的分组并行特性。在每一个 Phase，Control Unit 在控制读取
完原语索引信息对每一个模块进行配置之后，即进入对三个模块的控制执行状态，直至三个
模块的操作都完成（idle 信号拉高）。
Soma 和 Axon 之间可以通过行流水的方式工作，Axon 每计算完 1 行，Controller 给 Soma
一个 S_row_trigger 信号。Soma 每收到一个 S_row_trigger 信号，in_row_cnt 加 1；同时 Soma
每计算完（输出的）一行，in_row_cnt 减去一个高度方向的 stride 值 Sy（或 1），即再等待 Sy
行输入 Soma 才能开始计算。当 in_row_cnt 大于卷积核高度（或 0）时，Soma 可以才计算。
