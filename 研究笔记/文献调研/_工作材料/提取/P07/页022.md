5.3 处理器访问 SRAM
Axon Unit 有两套数据总线，分别访问数据空间、权重空间。InB 总线为读写数据总线，
控制从权重空间读出权重数据 W，写回 W 更新数据；InA 总线为读写总线，控制从数据空间
读出输入数据 X，并将计算结果 V 写回数据空间。
Axon Unit（数据处理器）的内存读写数据位宽为 32B，地址溢出指定数据空间大小时，
地址取余数。数据处理器访问优先级最高。
Soma Unit（神经元处器）有两套读写分离的地址数据总线，可以读写任意 SRAM 块
Mem0～Mem3，以提高 Move 原语执行的效率。读写数据位宽为 16B，地址溢出指定 memory
块大小时，地址取余数。
Router Unit（路由处理器）有一套读写地址数据总线，只访问参数空间 SRAM 块 Mem2。
路由处理器的读出位宽为 16B，写入数据位宽为 8B、2B 和 1B。
工作时，路由器按 8B 接收数据，写入 Mem2 相应的地址输入数据缓存地址。当一组数
据传输完整后，如每个 Phase 结束后或收到由发送端发来传输结束指令，由 Soma Unit 按 16B
位宽，根据原语将输入数据转移至数据存储空间中。
Axon Unit 将计算结果存入数据空间。当需要将 Axon Unit 计算结果发送到其它 Core 时，
由 Soma 处理器执行 Move 原语，根据原语中的地址将输出数据搬运到在 Router 中等效为
Mem3 的中间缓存中，再由路由处理器读取发送；或将数据直接存储 Mem2，再由路由处理
器读取发送。
Soma 处理器计算结果可以存入数据空间或 Mem2。当需要发送到其它 Core 时，Soma 处
理器可以直接将结果存入 Mem2 或 Mem3 中，由路由处理器读取发送。其中，Mem3 为 16B
寄存器组成的缓存单元，用于缓存 Soma 向 Router 发送需要 Core 间传输的数据。当 Soma 写
该缓存后该缓存写使能清 0，Router 发送器读取该缓存后，该缓存写使能置 1。
Mem0~Mem2 访问优先级：Axon Unit＞Soma Unit＞Router Unit。
进 一 步 ： (Read_PI) >Axon_InA RW > Axon_InB RW ＞ Soma Wr>Soma Rd ＞ Router
Rd>Router Wr。
Mem0~Mem2 的仲裁由 Mem 模块根据仲裁优先级产生，在各模块访问时根据各模块地址
产生相应的 rdy 信号，只有当相应的 rdy 信号为 1 时，各模块才能有效读写。
