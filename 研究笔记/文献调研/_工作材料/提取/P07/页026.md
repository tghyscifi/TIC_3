6.5 控制逻辑原语 3：PIC=0x02（ΣX+Bias\b）
6.5.1 原语功能简述
此原语是执行带偏置的向量累加操作，也可用于平均池化的求和操作，用于累加时，输
入也可以是二维矩阵或多维张量。原语执行时，X 可以为 3 值、uint8 或 int8、及 int32。int32
开启 1 组 8 个 MAC 进行计算，3 值和 int8、uint8 开启 4 组 8 个共 32 个 MAC 进行计算。
6.5.2 原语执行的计算
执行平均池化的加和操作时，包含 5 个循环，分别为输出高度 Oy 方向（L5）循环、输
出宽度 Ox 方向（L4）循环、输入输出通道 32B 分组 Km_num 方向（L3）循环、Pooling 核
高度 Ky 方向（L2）循环、Pooling 核宽度 Kx 方向（L1）循环。
5 for Oy = 0 : Oy_num ( Output fmap height )
4 for Ox = 0 : Ox_num ( Output fmap width )
3 for n = 0 : Km_num (Bias group/X_Km_group)
Sum[Oy][Ox][n] = Bias[n]/ b
2 for Ky = 0 : Ky_num ( Filter height )
1 for Kx = 0 : Kx_num ( Filter width )
Sum[Oy][Ox][n] += X[Oy][Ox][n][Ky_cnt][Kx_cnt]
执行向量累加操作时，可视(L1_num+1)*(L2_num+1)为向量累加次数 k（X1+X2…+Xk）。
