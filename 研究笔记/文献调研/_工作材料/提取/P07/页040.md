8.6.2 原语执行的计算
每个向量包括向量长度 length 和向量个数 num 两个参数。

向量长度 length 的关系决定着每一组向量的拼接关系：
1. length_out ≤ length_in, 输出的每一个向量为部分或全部的对应 in 向量元素；
2. length_in ＜ length_out ≤ length_in + length_ciso, 输出的每一个向量包括全部的对
应 in 向量元素和部分或全部的对应 ciso 向量元素。
3. length_in + length_ciso ＜ length_out, 输出的每一个向量包括全部的对应 in 向量元
素和全部的对应 ciso 向量元素，剩下的元素部分补 0；
向量个数 length 的不同数据的对应关系：
1. num_out < num_in 或 num_out < num_ciso 时，仅有 num_out 个 in/ciso 向量被搬运到
out 数据中，其余数据被抛弃；
2. num_out ≥ num_in 或 num_out ≥ num_ciso 时，全部的 in/ciso 向量被搬运到 out
数据中，向量计数大于 num_in/ciso 时全部补 0。
向量整合操作计算流程如下：
for num_out_cnt = 0 : num_out
for length_out_cnt = 0 : length_out
if length_out_cnt <= length_in ( Move in)
if num_out_cnt <= num_in
out[num_out_cnt][length_out_cnt] = in[num_out_cnt][length_out_cnt]
else
out[num_out_cnt][length_out_cnt] = 0
elif length_out_cnt <= length_in+length_ciso ( Move in)
if num_out_cnt <= num_ciso
out[num_out_cnt][length_out_cnt] = in[num_out_cnt][length_out_cnt - length_in]
else
out[num_out_cnt][length_out_cnt] = 0
