5. Memory Unit
5.1 模块概述及结构
Core 内 memory 为多片 SRAM 构成的 144KB 存储空间，用于存放神经元网络计算的权
重、数据以及参数等，采用统一管理，灵活配置使用。
Core 内 memory 由 5 片读写宽度为 16B（128b）的物理 SRAM 块组成，为 32KB×4+16KB。
在逻辑上被划分为三块 Memory：Mem0（读写宽度为 32B，大小为 64KB）、Mem1（读写宽
度为 32B，大小为 64KB）和 Mem2（读写宽度为 16B，大小为 16KB）。如下图 4-1 所示。
此外还包含一块大小为 16B 寄存器（等效 Mem3，实际在 Router 模块中）用来存储待发
送的输出数据，此模块可用于 Soma 和 Router 的数据交互。
图 5- 1 Memory 单元的基本结构示意图
基本工作模式：
Mem0~1 为权重、数据空间：权重、数据均按 32B(256b)为宽读写；
Mem2 设定为参数、缓存空间：Soma 16B 读写；Router 1B、2B、8B 写、16B 读；
Mem3 设定为单向输出缓存：Soma 16B 写；Router 16B 读（实现为 Router 中的寄存器）。
5.2 SRAM 块配置使用方式
在基本工作模式（mode0）下，Mem0～Mem1 为计算（权重、数据）存储空间，Mem2
为参数存储空间，Mem3 为 Soma 到 Router 的缓存。
Mem0、mem1 在使用时可以被分别指定给数据存储、权重存储，由 Control Unit 配置。
