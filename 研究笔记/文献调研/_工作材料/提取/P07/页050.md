4) 即时原语索引路由包格式（S = 1、TP = 00）
a. 发送即时原语索引时的路由包格式：
S TP Q X Y IN_PI B init_x init_y braod_x braod_y P
1 2 1 8 8 11 1 8 8 8 8 32
R[95:95] = S 数据包与即时原语包标志位，S =1 表示即时原语；
R[94:93] = TP 路由包类型，此时 TP =00 表示发出的即时原语包；
R[92:92] = Q 多播与普通即时原语包标志位，Q= 0 表示普通即时原语数据包，Q = 1 表示
多播即时原语数据包；
R[91:84] = dx[7:0], 目的簇的水平相对距离（int 8），范围[-128, 127]；
R[83:76] = dy[7:0], 目的簇的竖直相对距离（int 8），范围[-128, 127]；
R[75:65] = IN_PI，即时原语索引；
R[64:64] = B，即时原语多播是否需要返回应答标志位，B = 0 表示不需要返回多播应答，
B = 1 表示需要返回多播应答；
R[63:56] = init_x，发送即时原语索引源 core 的-dx 值；
R[55:48] = init_y，发送即时原语索引源 core 的-dy 值；
R[47:40] = braod_x，当即时原语在 group 内多播时 group 内源 core 地址，braod_x = - PI_Nx。
R[39:32] = braod_y，当即时原语在 group 内多播时 group 内源 core 地址，braod_y = - PI_Ny。
R[31:0] = P，保留。
