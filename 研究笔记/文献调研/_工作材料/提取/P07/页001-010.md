1. 概述
1.1 设计定位
Tianjic X1 的设计目标是探索大规模时空复杂度的新计算架构。Tianjic V2 成功实现了对
计算机科学导向的传统人工神经网络和计算神经科学导向的脉冲神经网络的同时支撑和计算
架构上跨模态融合，在此基础上，Tianjic X1 旨在适应神经网络的高速变化带来的通用性需求，
进一步提高芯片的灵活性和可重构能力，从而同时实现对于多种神经网络的独立运行和异构
协同建模的高效支撑。
具体而言，芯片需要面对类脑神经网络算法中丰富多样性以及日渐增长的多网络协同工
作的趋势。
类脑算法具有丰富的多样性：1）编码方式的多样性：比如在传统神经元通过高精度的激
活值来进行信息的传递，而在脉冲神经元则通过用 0-1 表示的脉冲构成的序列来进行信息的
传递，更复杂的；2）网络结构的多样性：多个神经元可以通过不同的连接关系构成不同的网
络结构，常见的连接关系包括全连接结构、卷积连接和反馈连接等；3）存算负载的多样性：
在网络中的不同层，由于输入输出大小的不同以及结构参数的不同，会有不同的计算量和存
储量的需求。这些不同的多样性均需要芯片具有高的灵活性以支撑。
图 1- 1 类脑算法的多样性
多网络融合协同工作的趋势：随着处理问题的复杂程度不断增加，单一网络已经无法对
应，出现了多网络协同工作的趋势。不同类型的网络可以通过串联的关系顺序地处理统一任
务，也可以并行的协同辅助处理，此外，还可以通过网络之间的工作调度控制处理不同任务
的网络协同工作，从而构成一个大的系统。不同地网络不但可能在信息的传递处理上存在不
同，而且还可能具有不同的触发执行周期。实现多网络的高效协同对芯片设计提出了更高的
需求。

2.1 基于原语指令的配置方式
功能核设计采用基于原语指令译码执行的操作机制，每个功能核预留 16 条计算原语指令
（宏指令），每条原语的指令长度为 32B。原语分别由功能核中不同执行单元译码后执行。各
原语执行单元在功能核控制单元的调度下从核内存储单元中读取指令单元参数，之后对原语
进行译码，并根据原语指令的译码结果，从核内存储单元中（或者从核间路由接口接收数据）
读取数据，执行相应的操作，再将核内存储单元中去（或者发送到核间路由网络中）。

2.2 功能核的模块划分
按照原语的调度、执行和数据存储的需求，功能核被划分为了 Controller、Memory、Router、
Axon、Dendrite 以及 Soma 这 6 个功能单元，如下图 2- 1 所示。
其中：
Control Unit： Core 的运行控制单元，实现基于原语的指令调度；
Memory Unit： 多片 SRAM 构成的存储空间，用于存放神经元网络计算的权重、数据以
及参数等，采用统一管理，灵活配置使用；
Axon Unit： 实现向量、矩阵运算的输入输出数据的读写及类型转换等；
Dendrite Unit： 高并行的乘加计算（MAC）阵列，和 Axon 共同进行矩阵/向量计算；
Soma Unit： 实现 Core 内的数据搬运、张量比较以及 LUT 激活函数和 LIF 神经元等
非线性运算；
Router Unit： 实现 Core 间各类数据传输的路由控制逻辑。
图 2- 1 Tianjic X1 的功能核（Core）结构示意图
1. Core 的运行由 Controller Unit，即 PI 处理器（PI processor）控制管理。PI 处理器负责
根据预置的静态原语组堆栈信息，调用数据处理器（Data Processor，即 Axon Unit）、神经元
处理器（Soma Unit）以及路由处理器（Router Unit）；PI 处理器也负责响应和处理通过路由
接受到的即时原语执行请求信息。PI 处理器中存储原语执行堆栈的索引信息。根据索引信息，
PI 处理器生成待执行的 PIC 在 Memory 中的地址指针，并发送给数据处理器、神经元处理器
及路由处理器等。各处理器收到 PIC 启动信号后，到相应地址中读取 PIC 全码、执行相应操
作并将执行状态反馈给 PI 处理器。

2. 数据处理器(Axon Unit)根据 PIC 参数，从 Memory 中读取待处理的数据 InA 及 InB，
经数据格式整理、类型变化后，逐时钟送到矩阵处理器。并将矩阵处理器的计算结果，如膜
电位累加值，写回 memory 中。数据处理器仅用于高速处理大并行度向量、矩阵计算任务，
不参与 Core 间数据收发。
3. 矩阵处理器（Dendrite/Matrix）为高速并行乘加器（MAC）阵列，不直接访问 memory。
矩阵处理器的输入输出数据及其计算过程均由数据处理器（Axon Unit）管理。Axon 模块的
译码结果决定着乘加器阵列中的乘加器的工作模式、开启数量和阵列组织方式。
4. 神经元处理器（Soma）用于从 Memory 中读取数据，进行数据比较、数据搬运整理和
神经元的非线性变换操作。神经元处理器可以访问 Memory 模块中用于数据收发缓存的空间，
从而参与 Core 间数据收发。神经元处理器（Soma）可以将待发送数据搬运到发送缓存区或
者将接收缓存区中存储的数据搬运出来。
5. 路由处理器（Router）用于 Core 间数据收发、数据的中继、多播以及即时原语组执行
请求和应答信号的传递。
6. 存储模块（Memory）为多片 SRAM 构成的 144KB 存储空间，用于存放神经元网络计
算的权重、数据以及参数等，采用统一管理，灵活配置使用。当来自执行单元的不同数据接
口出现 Memory 的访问时，由存储模块按照预定优先级进行仲裁。

每个 Core 可以处理由多个原语组构成的原语组堆栈，在生成芯片的配置时，原语组堆栈
会被转化为 Controller 中的多组原语组索引信息和 Memory 中的多条原语参数信息。在每个工
作周期时，由 Controller 读取一组原语组索引信息生成相应的地址指针，控制 Axon、Soma
和 Router 模块从 Memory 中读取对应的原语参数译码执行。
由于存储和触发执行的机制不同，一条原语组的在执行上会被分为静态原语组合即时原
语组。
静态原语组：由执行 Core 的 Controller 从内部自动连续调用执行。需要执行的静态原语
组的原语指令参数按照原语组执行顺序连续的存储在 Memory 中，每个原语组中各原语的执
行情况（是否执行）作为索引被存储在 Controller 的静态原语组索引寄存器中，在执行时
Controller 依次从静态原语索引寄存器中读取一组原语的索引信息并控制各模块从 Memory 中
读取原语指令参数并执行。
即时原语组：由其他的 Core 触发执行 Core 执行。需要执行的即时原语组的原语指令参
数预先存储在 Memory 中，与之对应的即时原语索引信息除了原语组内各模块的执行情况之
外，还包括了即时原语存储位置（位置偏置）信息。即时原语索引信息存储在触发 Core 中，
由触发 Core 发送包含即时原语信息的即时原语路由包触发执行 Core 来执行。
