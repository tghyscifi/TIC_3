6. Axon Processor
6.1 模块概述及结构
Axon 单元是功能核 Core 中，高速并行处理的数据整理单元，主要实现输入、输出数据
整理功能，包括数据缓存、时序对齐、类型变换以及加载常数等。同时，还可以实现数据移
位、变序、重组等操作（Option）。
Axon 单元也是 Dendrite 处理器（MACs 阵列）与 memory 之间的读写访问控制器。包括
生成 X、W、Y 等向量和权重读写地址、使能控制信号及时序。
Axon 单元实现 MACs 阵列的工作模式和使能控制。由于 Axon 承担数据整理功能，把卷
积、点乘、向量矩阵乘、累加这些复杂的计算，转换为一系列 Dendrite 的乘加器阵列(MACs)
可执行的乘加运算。实现如 MACs 使用数量、各 MAC 的 0 输入禁用等 MACs 阵列的能耗优
化控制等。

从结构上来看，Axon 模块包括：
1) 1 个 6 级硬件循环计数器（HWL）；
2) 4 个地址产生模块（AGU）及相应的读写生成逻辑；
3) 以及一块数据缓存整理模块（Data Buf.）。
Axon 与 Controller 模块、Memory 模块和 Dendrite 模块相连。
