10. Router Processor
10.1 路由概述
路由模块分为两级路由：Core 间路由（片内路由）和片间路由。路由包在芯片内部 Core
与 Core 之间的传输过程由 Core 间路由负责，采用同步并行通信方式；片间路由用于路由包
出入芯片的路由过程，采用异步串行通信方式。
