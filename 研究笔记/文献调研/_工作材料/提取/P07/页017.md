4.2.1 静态原语组 static PI 的存储及索引方式
如图 4- 2 所示，在每一个 Core 中，多条静态原语参数被压缩存储在 Memory 中，起始地
址为 Addr_static_PI_base，通过存储在 Control Unit 里 Static_PI_Buf 中对应的静态原语组索引
信息来索引读出。在存储时，每组包括 Axon-Dendrite、Soma1、Router、Soma2 操作的一组
原语被存储在一起，而其中的空操作原语则被压缩不需要存储。对应的在 Control Unit 中存储
的原语索引信息为对应每一组内 Axon-Dendrite、Soma1、Router 和 Soma2 是否为有效原语的
指示标志。当需要有数据从 Mem0/1 直接/经过计算后通过 Router 发送出去时，需要通过 Soma1
操作实现数据的搬运；当 Router 接收到数据之后最终需要存储在 Mem0/1，通过 Soma2 操作
实现数据的搬运。预配置原语在 Memory 中的原语参数和在 Control Unit 中的原语索引均按执
行顺序排列，因此每条原语索引不需要存储额外的地址信息。每个 Core 支持最大支持 32 条
预配置原语，因此 PI_Idx_Buf 的大小为 32×4b = 128b，预备置原语在 Memory 中所需的存储
空间为不超过 32×32B×4 = 4KB。
4.2.2 即时原语组 instant PI 的存储及索引方式
即时原语的压缩存储时的方式与静态原语相似，但是除了表示各模块是否为有效原语的
A/S1/R/S2_valid 标志位（共 4bit）之外，还包括表示其在 Mem2 中相对于静态原语结束的偏
置位信息 PI_addr_offset（6bit，保证大于 16*4/2= 32），一个一个用于区分是来自同节拍时序
组还是不同节拍时序组的标志位。一个即时原语组中起始原语（第一个不为空操作的模块原
语 ） 的 地 址 索 引 方 式 为 Addr_static_PI+Addr_instant_PI_base +(PI_addr_offset * 2) ， 其 中
Addr_instant_PI_base 为即时原语参数存储的起始地址。即时原语组索引采用 instant_PI_FIFO
