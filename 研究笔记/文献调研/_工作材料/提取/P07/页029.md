6.7 控制逻辑原语 5：PIC=0x43（A•X+Bias\b）
6.7.1 原语功能简述
PIC=0x43 原语下，V =A•X+Bias\b，与 0x03 不同的是，A 和 X 的向量长度可以不同，X
的长度可以是 A 的整数倍，以此实现 A 向量的循环使用。最多可以实现 X 为 3 维的 Tensor
按一定规律取点进行点乘运算。由点乘与加偏置两个计算环节组成。其中偏置值可以是常数
偏置 b(int32)，也可以是偏置向量 Bias(32bit)，系数向量 A 仅支持 int8 和 uint8 两种数据类型。
常数偏置 constant_b 存放在原语寄存器中。由于需要使用乘法器，故向量点乘原语支持输入
向量 X 为三值、uint8、int8 三种读出补足为 int9 的数据类型的计算。使用一组 MACs（32 个
有效）并行计算。
6.7.2 原语执行的计算
计算与 0x03 原语类似，A 的数量为（L3_num+1），需要在 L4、L5 循环内循环使用。
5 for L5_cnt = 0 : L5_num (Reserved/Oy)
4 for L4_cnt = 0 : L4_num (Reserved/Ox)
3 for L3_cnt = 0 : Km_num (Bias_group/X_Km_group/A_group)
Vout[L5_cnt][L4_cnt][L3_cnt] = Bias[L3_cnt]/ b
Vout [L5_cnt][L4_cnt][L3_cnt] += A [L3_cnt]×X[L5_cnt][L4_cnt][L3_cnt]
