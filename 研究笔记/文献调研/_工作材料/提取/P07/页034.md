7.3.1 D_mode == 1, 执行 V = ∑X*W + Bias/b（CNN）
此时计算模式为数据与权重相乘，在此模式下每一组内的 32 个乘累加器接收 32 个不同
的 InB 数据 InB[31:0][8:0]；不同组间共享这 32 个 InB 数据。同时，每一组对应一个不同的
InA 数据，四组的 InA 输入取 InA 输入中的前 4 个数据 InA[3:0][8:0]。此时 MAC 的使能以及
加法器、乘法器使能均为 1，当乘法计算完成后进行累加，当累加结果饱和溢出时候进行饱
和截取。
在 D_mode == 1 的模式下，Axon 传过来的只有 int9 的数据，MAC_in_grp_num == 1，每
组 32 个 MAC 全开。
7.3.2 D_mode == 2，执行 V =∑X + Bias/b
此时计算模式向量相加，此模式下在 32B 带宽下，通过 InA=通道可以分别接收 8 个 int32、
32 个 int9，128 个 Tenary 的数据。
当 D_in_type == 0 时，输入数据为 int32，MAC_grp_num == 0, MAC_in_grp_num == 0，
开启 8 个 MAC；
D_in_type == 1 或 2 时，输入数据为 int9， MAC_grp_num == 0, MAC_in_grp_num == 1,
开启 32 个 MAC；
D_in_type == 3 时，输入数据为三值， MAC_grp_num == 3, MAC_in_grp_num == 1，开
启 128 个 MAC；
