6.4 控制逻辑原语 2：PIC=0x81（CNN1）
6.4.1 原语功能简述
该卷积原语对应的是对具有较小输入通道数（FM 数<8，通常为 RGB 或灰度图）输入图
像的卷积操作。由于和 0x41(CNN0)具有不同的输入特征图存储方法，因此 0x81(CNN1)原语
设计也和 0x41 具有不小差异。原语支持与偏置向量 Bias 作累加。四个方向的 padding 参数不
能直接设置，而需要存储时在 Memory 中补零；支持膨胀卷积，可以设置膨胀系数 Ex、Ey
（系数为 1 即为常规卷积，参数默认是 0）。原语执行时，X 可以为 uint8 或 int8（没有专门对
三值数据类型优化，三值需按 int8 存储模式实现），W 可以为 3 值、uint8 或 int8。可同时进
行 4×32=128 个乘累加计算。当输入 X 为 3 值时，在 Memory 存储时自动扩充为 8bit，即 X
三值的计算逻辑与 8bit 计算逻辑相同。
6.4.2 原语执行的计算
CNN1 模式用以下六级循环 L0—L5 完成含有三个维度（图像宽度 Px、图像高度 Py、输
入通道数 M）的向量 X 和四个维度（卷积核宽度 Kx、卷积核高度 Ky、通道数 M、卷积核个
数 N）的权重 W 的卷积运算。
与 CNN0 模式不同的是将控制输入通道 m 方向循环移到 Ky 循环后。
1 for Oy = 0 : Oy_num ( Output fmap height )
2 for Ox = 0 : Ox_num ( Output fmap width )
3 for n = 0 : n_num ( Output channel)
Out_FM [Oy][Ox][ n ] = Bias [ n ] (or 0)
4 for Kx = 0 : m_num ( Input channel)
5 for Ky = 0 : Ky_num ( Filter height )
6 for m = 0 : Kx_num ( Filter width )
Out_FM [ Oy ][ Ox ][ n ] +=
