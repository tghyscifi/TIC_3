3.3 多相位触发组
Tianjic X1 的节拍触发时序采用众核分组触发，160 个 Core 可以任意组合为 32 个相位触
发组，组合在同一组内的各 Core 具有相同的触发控制逻辑（相位时序 phase 和时间步时序 step）。
实现分组控制的逻辑示意图 3- 3 如下所示：
图 3- 3 众核分组触发控制模块示意图
每一组相位触发器，根据 trigger_sel[X]信号从 4 个节拍触发器选择对应的 step_finish[S]
和 trig_pos[S]信号。
每一组相位控制器，均有一个掩膜寄存器 core_group_en[X]，用于筛选各 Core 的 finish
信号。在各组相位控制器的掩膜寄存器中，被选通的 Core 的对应位设置为 1，未被选通的 Core
的对应位设置为 0。
运行中，在每个 phase 各组相位控制器依据掩膜寄存器 core_group_en[X]和 160 个 Core
的 core_finish[i]信号来生成表示当前组内所有 Core 运行结束信号 core_grp_finish[X]。若寄存
器中为 1 的位置对应的 Core 的 core_finish[i]均为 1，则 core_grp_finish[X]信号为 1。
相位触发有三种工作模式，由外部输入单次触发允许标志 P_single 和自适应允许标志寄
存器 P_adapt[X]决定。
1) 单次触发（P_single==1）：
在 选 择 的 trig_pos[S] 到 来 时 产 生 一 个 相 位 脉 冲 pck_grp[X] ， 之 后 等 待 下 一 个
trig_pos[S]。在 trig_pos[S]到来时也产生 sck_grp[X]。
2) 定时触发（(P_single==0)&(P_adapt[X]==0)）：
在选择的 trig_pos[S]到来时，相位控制器开始计数，并产生一个相位脉冲 pck_grp[X]。
之后每计满 clk_in_phase[X]，重置计数器开始新的 Phase 的计数，产生一个相位脉冲
pck_grp[X]。Step_finish 为 1 时，停止计数。
