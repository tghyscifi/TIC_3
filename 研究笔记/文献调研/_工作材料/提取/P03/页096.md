拓扑排序后遍历 nodes 时，可以保证每个结点在被访问之前产生其输入数据的结
点一定已经被访问过，从而避免了可能无法进行精度推理的问题。
算法 5.3 计算图的拓扑排序算法
输入：graph, in_degrees
输出：nodes_topo
for node in graph.nodes do
in_degrees[node] = len(graph.input_connections[node])
end for
node_zero_in = [n for n in in_degrees if in_degrees[n] == 0]
while not is_empty(node_zero_in) do
n = node_zero_in.pop()
nodes_topo[n] = graph.nodes[n]
for o in graph.output_connections[n] do
in_degrees[o] = in_degrees[o] - 1
if in_degrees[o] == 0 then
node_zero_in.append(o)
end if
end for
end while
return node_topo
算法5.3中， 首先统计每个结点的入度， 将结果存入字典in_degrees 中， 然后统
计初始状态下入度为 0 的结点。当入度为 0 的结点数量不为 0 时，从其中拿出一
个结点，将其放入拓扑排序后的结点列表中，并将使用当前结点输出数据的结点
的入度减 1。如果这些结点中有结点的入度变为 0，则将该结点放入入度为 0 的结
点列表中。重复上述操作，直到列表中没有入度为 0 的结点，则拓扑排序完成。
