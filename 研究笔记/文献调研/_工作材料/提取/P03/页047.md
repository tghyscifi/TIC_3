class SNN(Model):
def __init__(self, T, mode) :
super (SNN, self). __init__(time_interval=T, mode =mode)
self.linear = torch.nn.Linear(in_features=784, out_features =10)
self.lif = LIFNeuron(v_th=1, v_leaky_alpha =0.5, v_leaky_beta =0,
v_reset=0, v_leaky_adpt_en =True, v_init =0)
def forward(self, x, v =None):
x = self.linear(x)
spike, v = self.lif(x, v)
return spike, v

该 SNN 模型中构建了具有一层 10 个神经元的脉冲神经网络， 其中linear 完成

SNN 类继承自 Model 类，Model 类是 SNN 编程框架中构建脉冲神经网络的基
类，包含两个属性，time_interval 和 mode，前者代表时间窗参数，表示在 SNN 的
训练与推理过程中，神经元接受输入并维持膜电位等状态的时间窗长度，当时间
窗的计时结束后，神经元将状态恢复至初始状态，准备接受下一个输入序列；后
者代表脉冲神经网络的输入模式：第一种模式用于处理输入是编码好的脉冲序列，
称为 SEQUENTIAL 模式； 第二种模式处理静态输入， 此时脉冲神经网络的第一层
会被用作编码层来将静态输入编码成脉冲序列，这种模式称为 STA TIC模式。
可以注意到，SNN 中的前向推理方法只完成了单个时间步的脉冲神经网络的
计算，如果想执行 time_interval 个时间步的计算，可以直接调用父类 Model 中提
供的 multi_step_forward 方法， 该方法的伪代码见算法2.1， 其中𝑥 代表网络的输入，
𝑣 代表各种脉冲神经元状态的初始值， 例如膜电位的初始值，𝑚 代表脉冲神经网络
的输入模式，𝑇 代表时间窗大小，𝑓 代表网络单个时间步的前向推理方法， 返回值
为每个时间步的输出脉冲组成的输出序列。
