2.2.3 脉冲神经元在中间表示中的信息表示与记录
以 SpikingJelly [42] 为代表的现有 SNN 编程框架往往是针对特定的后端硬件
（如 Nvidia 的 GPGPU）进行开发设计的，如果想要将编程框架扩展到其他硬件后
端，则需要在编程框架内部实现描述的 SNN 模型到不同硬件后端的转换（例如到
Lynchip 或 Loihi） ，缺少一种通用的输出中间表示将编程框架与后端完全解耦。假
设有 𝑀 种编程框架和 𝑁 种后端，则需要 𝑀𝑁 次适配才能让每个编程框架支持所
有后端。为了能够以一种统一的方式适配广泛的编译器和硬件后端，本文提出的
SNN 编程框架采用了计算图形式的 IR 给出编程框架的输出，如果该计算图 IR 能
够成为一种通用的标准，则可以将软硬件适配的工作量下降到 𝑀 + 𝑁 次。
为了能够尽可能地兼容现有的软件生态，本文选择以 ONNX 计算图 [70] 作为
编程框架的输出 IR。但目前 ONNX 还没有对 SNN 的支持，因此本文在编程框架
层面实现了 ONNX 的扩展从而实现对 SNN 的支持，扩展的 ONNX 计算图即为本
文提出的一种面向 SNN 领域的通用中间表示。

class LIF(torch.nn.Module):
def __init__(self, v_th, v_leaky_alpha, v_leaky_beta,
v_reset, v_leaky_adpt_en, v_init) :
super (LIF, self). __init__()
self.reset = HardUpdateAfterSpike(value=v_reset)
self.update = Update(v_init=v_init)
self.fire = FireWithConstantThreshold(
surrogate_function=Rectangle, v_th =v_th)
self.leaky = Leaky(
alpha=v_leaky_alpha,
beta=v_leaky_beta, adpt_en =v_leaky_adpt_en)
def forward(self, u_in, v) :
v_update = self.update(u_in, v)
spike = self.fire(v_update)
v = self.reset(v_update, spike)
v = self.leaky(v)
return spike, v
