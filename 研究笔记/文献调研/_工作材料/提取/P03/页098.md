5.3.4.2 任务组连接生成
5.3.4.1节中生成了任务组内的连接， 本节在此基础之上通过GroupConnector 生
成任务组之间的连接。算法5.4描述了任务组连接生成方法。
算法 5.4 任务组连接生成算法
输入：task_graph
for c_block in task_graph.groups do
node = task_graph.ctx.mapping_dict[c_block]
for o in node.output_nodes do
next_c_block = task_graph.ctx.mapping_dict.inverse[o]
input_s_blocks = task_graph.groups[c_block]
for s_block in input_s_blocks do
data = task_graph.ctx.mapping_dict[s_block]
if node.output == data.name then
create_edge(c_block, s_block)
end if
end for
end for
end for
