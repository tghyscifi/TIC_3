如果 core_id 这个列表中不止一个元素，如第一行例子，那么代表该发送core 的这部分数据
包要发给几个 core，list 中的 core（除最后一个）都是多播 core。core_id: [((0,0),(0,1)) ,((0,0), 
(2,1))]，就代表该 core 要发送数据给 core（0,1），core（0,1）再把数据多播给（2,1），（0,1）
和（2,1）收到的都是同一块数据。 
data_num：发送给对应 core 的数据包的个数 
T_mode：单包/多包 
Rhead_num: 使用表头的个数 
sync_en: 跨组数据传输时是否需要 phase 同步（默认是 0, 可以不写这个 key） 
sync_phase_num：接收数据的 core 在执行第几个 phase 时收数据（从 0 开始，sync_en 为 1
时填写） 
 
对应地，当配置路由为接收数据时，同时需要配置数据来源 core 的相关信息
