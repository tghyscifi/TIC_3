清华大学类脑计算研究中心 机密文件 
 
0x02 Axon（ΣX+Bias\b） 
参数 说明 范围 
avg_pooling_en pooling 模式/向量相加模式 True/false 
pad_on 是否 pad True/false 
InA_type 输入 X 类型 [0]int32[1]int8[2]uint8 [3]Tenary 
Load_Bias Dendrite 赋初值标志位 [0/1]常数偏置[2/3]向量偏置 Bias 
cin 输入向量 channel 个数 根据不同数据类型配置 32B 的
整数倍 
Bias_length 偏置向量长度 32n(即保证 32B 整数倍) 
Input_fm_Px 输入 FM 宽度 非硬件底层实际原语参数 
Input_fm_Py 输入 FM 高度 非硬件底层实际原语参数 
pad_top 图像上方补零行数 0~7 
pad_down 图像下方补零行数 0~7 
pad_left 图像左面补零列数 0~7 
pad_right 图像右面补零列数 0~7 
pooling_Kx Pooling 核宽度 
（Array_num = Kx×Ky） 
1~16 
pooling_Ky Pooling 核高度 
（Array_num = Kx×Ky） 
1~16 
pooling_Sx X 方向步长（仅池化模式） 1~7 
pooling_Sy Y 方向步长（仅池化模式） 1~7 
Reset_Addr_A 载入原语后 InA 地址复位标志 [0]不复位 [1]复位 
Reset_Addr_V 载入原语后 V 地址复位标志 [0]不复位 [1]复位 
Addr_InA_base 输入数据 InA(向量数据 X)地址
区间的初始地址 
按4B 寻址 
0x0000~0x7fff 
Addr_V_base 输出 Vout 初始地址 按4B 寻址 
0x0000~0x7fff 
Addr_Bias_base 偏置向量的初始地址 
按4B 寻址 
0x0000~0x7fff 
A2S2_mode Axon 允许Soma2 原语的启动
方式 
[0]Axon 计算完毕才允许启动  
[1]Axon 未计算完也允许启动 
 
注意： 
1. 做平均池化且有 padding 时，原语参数 Addr_InA_base 会在用户配置的基础上做一个偏
移。即最终原语参数的 Addr_InA_base = Addr_InA_base(用户配置) – Addr_start_offset，
但输入数据的实际存储位置仍是用户配置的 Addr_InA_base。该过程有软件自动完成。 
2. 做平均池化且没有 padding 时，即 pad_on = False 时，四个方向的 pad 参数都会置零 
3. avg_pooling_en = False 时，就可以做普通的向量累加，其中累加向量的次 数
(X1+X2+X3+…+Xk)，k=Pooling_Kx×Pooling_Ky。每个输入向量 X 的深度是 cin，添 加
偏置向量 Bias 时，cin=Bias_length。 每个输入向量X 的数量由 Input_fm_Px×Input_fm_Py
决定，优先使用 Input_fm_Py（即 Input_fm_Px=1），fm 累加的时候再增加使用 Px。
