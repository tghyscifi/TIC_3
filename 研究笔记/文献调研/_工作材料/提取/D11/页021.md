路由包头接口函数说明 
函数参数分为两种形式： 
当原语参数中 Rhead_mode=1 时，应使用如下形式： 
addRHead(S=0, T=1, P=0, Q=0, X=0, Y=0, A=0, pack_per_Rhead=255, A_offset=0, Const=0, 
EN=1) 
pack_per_Rhead:0 表示 1，范围 0~4095，表示这个包头发送 1~4096 个包 
Const: 0 表示 1，范围 0~127，表示连续发送 1~128 个包 
A_offset：0 表示 1，范 围0~4095， 表示连续发送Const+1 个包后 A 的偏移量，A=A+A_offset 
 
 
当原语参数中 Rhead_mode=0 时，应使用如下形式： 
addRHead(S=0, T=1, P=0, Q=0, X=0, Y=0, A=0) 
 
addRHead 函数的调用顺序即为包头的存储顺序

core 间路由关系的表征： 
当配置路由发送原语时，同时需要配置数据接收 core 的相关信息 send_destin_core_grp[]： 
send_destin_core_grp[ 
{core_id: [((0,0),(0,1)) ,((0,0), (2,1))], data_num: 10, T_mode:0/1, Rhead_num:1, sync_en:0}, 
{core_id: [((0,0),(0,2))], data_num:10, T_mode:0/1, Rhead_num:1, sync_en:1, sync_phase_num:2}] 
数据要发送给多少个 core（非多播中继）就有几个字典。 
其中，core_id 填写的是接收数据 core 的绝对坐标，每个接收数据 core 的绝对坐标都是二维
元组，第一维(0,0)代表其所在的 chip 坐标，第二维代表其 chip 内坐标，均是先 x，后 y。
