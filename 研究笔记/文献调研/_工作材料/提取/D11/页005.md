
## PDF第5页

清华大学类脑计算研究中心 机密文件 
 
0xX5 Soma Pooling 
参数 说明 范围 
PIC_Mode Max/Min 比较 0：max 1：min 
pad_on Pad 使能 True/false 
type_in X 数据类型（DW） 0:int32，1:int8，2:无效 3:Ternary 
type_out Y 数据类型 0:int32，1:int8，2:无效 3:Ternary 
cin 输入 channel 数 
Type_in=0 时:1~1024 
Type_in=1 时:1~4096 
Type_in=3 时:1~16384 
cout 输出 channel 数 
Type_out=0 时:1~1024 
Type_ out =1 时:1~4096 
Type_ out =3 时:1~16384 
Input_fm_Px 输入 FM 宽度 满足不等式* 
Input_fm_Py 输入 FM 高度 满足不等式* 
pad_top 图像上方补零行数 0~7 
pad_down 图像下方补零行数 0~7 
pad_left 图像左面补零列数 0~7 
pad_right 图像右面补零列数 0~7 
pooling_Kx Pooling 核宽度 1~16 
pooling_Ky Pooling 核高度 1~16 
pooling_Sx X 方向步长 1~7 
pooling_Sy Y 方向步长 1~7 
CMP_C 一组比较器池化层比较器初始值(常数)  int32 
in_cut_start 输入 32b 输出 8b/2b 时的截取起始位 0~15:从最低位隔位截取 
Reset_Addr_in 载入原语后复位 X 地址寄存器控制位 [0]不复位 [1]复位 
Reset_Addr_out 载入原语后清除 Y 地址寄存器控制位 [0]不复位 [1]复位 
Row_ck_on 行流水处理标志位 [0]不流水 [1]流水 
Addr_start_in 输入数据 X 初始地址 
有符号数，按 4B 地址填写 
0x0000~0x8fff 
Addr_start_out 输出数据 Y 初始地址 
按 4B 地址填写 
0x0000~0x8fff 
in_row_max Axon-Soma 缓存区可以存储的行数 1~256 
mem_sel 输出结果写入 mem2/mem3 标志位 [0]写入 mem2 [1]写入 mem3 
*分别满足以下不等式： 
1 ≤ ((Input_fm_Px + Pad_left + Pad_right) – Pooling_Kx) / Pooling_Sx + 1 ≤ 256 
1 ≤ ((Input_fm_Py + Pad_top + Pad_down) – Pooling_Ky) / Pooling_Sy + 1 ≤ 256 
注意： 
1. 所有参数都是实际值，不用减 1。生成的原语参数会自动配置好 
2. 有 padding 时，原语参数 Addr_start_in 会在用户配置的基础上做一个偏移。即最终
原语参数的 Addr_start_in = Addr_start_in (用户配置) – Addr_start_offset， 但输入数据
的实际存储位置仍是用户配置的 Addr_start_in。该过程有软件自动完成。
