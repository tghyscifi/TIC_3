0x09 Router 
参数 说明 范围 
Rhead_mode 确定单个路由表发送数据数 
Rhead_mode=1，每个包头占 8B 
Rhead_mode=0，每个包头占 4B 
[0]单一数据路由表头 
[1]路由表头发多个数据 
T_mode 单包发送/多包发送标志位 [0]单包发送 
[1]多包发送 
Soma_in_en 是否和 Soma 进行数据交互的标志 [0]不和 Soma 进行数据交互 
[1] 和 Soma 进行数据交互 
CXY 当前 core 的中继/多播模式 [1]表示多播[2]表示中继 
[0]/[3]表示无多播/中继 
Send_en 本 core 是否发送数据标志位 [0]不发送数据 
[1]发送数据 
Receive_en 本 core 是否接收数据标志位 [0]不接收数据 
[1]接收数据 
Send_number 本 core 发送的路由包数（包含
EN=0 的数量） 
0~4095 表示 1~4096 
Dout_Mem_sel 待发送数据的 Memory 选择 0：Mem2 
1：Mem3 
Addr_Dout_base Mem2 待发送数据的起始地址 0x000~0xfff，4B 寻址 
Addr_Dout_length Mem2 待发送数据的最大地址长度 无符号数，按 16B 计数 
0~1023 表示 1~1024 个 16B 
Addr_Rhead_base Mem2 存储本地路由表的起始地址
（配置以 mem2 为基址的偏移地址） 
0x000~0xfff，4B 寻址 
Addr_Rhead_length Mem2 存储本地路由表包头长度 无符号数，按 16B 计数，0~255
表示 1~256 个 16B 数据 
Addr_Din_base 接收数据在 Mem2 存储起始地址（配
置以 mem2 为基址的偏移地址） 
0x000~0xfff，4B 寻址 
Addr_Din_length 接收数据在 Mem2 存储的长度 0~4095 表示 1~4096（单包时表
示 1B 的长度（个数），多包时
表示 8B 的长度（个数）） 
Receive_number 本 core 应接受结束标志总数，包括中
继/多播包的结束标志 
无符号数，0~4095 表示 1~4096 
Relay_number 中继/多播包总数 0~4095 表示 1~4096 
Nx 当前 core 的 x 方向多播步长 -64~63 
Ny 当前 core 的 y 方向多播步长 -64~63 
Send_PI_en 是否发送即时原语标志位 [0]不发送 [1]发送 
Back_sign_en 是否需要返回应答 [0]不返回 [1]返回 
Send_PI_num 应发送即时原语个数 无符号数，0~31 表示 1~32
